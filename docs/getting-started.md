# 安装与上手

安装包在 [GitHub Releases](https://github.com/Sraw/youmo-ime/releases)。目前只有一个版本，不含语音输入，也不申请录音权限。应用不联网；下载后可用 `SHA256SUMS.txt` 校验。

## 首次启用

1. 打开知了猴输入法，按向导进入系统的屏幕键盘设置并启用它。Android 对所有第三方输入法都会显示输入隐私警告。
2. 在系统键盘选择器中选择知了猴输入法。
3. 应用启动 Fcitx5 后会自动启用 Rime。键盘采用共用的全键盘布局；Rime 方案决定如何解释按键。

知了猴输入法只提供 Rime 引擎，**安装包不附带任何输入方案或词典**。首次使用前请按[Rime 输入](rime.md)添加方案并部署。

## 从旧版本升级

升级会保留应用设置和键盘数据；旧版拼音、双拼、九键、码表、英文和语音引擎不再提供。备份中旧 `engine/` 数据不会被导入。Rime 用户数据位于独立的 Rime 用户数据目录，通常可继续使用；如未显示方案，请检查该目录中的方案文件并重新部署。

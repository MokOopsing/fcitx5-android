# 常见问题

## 隐私与权限

**输入法会上传我打的字吗？**

不会。应用不申请网络权限；输入和 Rime 用户数据保存在设备本地。

**系统启用输入法时为什么提示可能收集输入内容？**

这是 Android 对第三方输入法的通用提示。知了猴输入法不联网。

**应用需要录音权限吗？**

不需要。本版本不包含语音输入。

**Rime 会记住什么？**

这由当前 Rime 方案和用户配置决定。Rime 用户数据位于应用外部文件区的 `data/rime` 目录，可在 Rime 设置页打开。

## 方案和词库

**为什么没有候选词？**

应用不附带 Rime 输入方案或词典。请按[Rime 输入](rime.md)安装方案及其依赖文件，然后部署。

**怎样换机或备份方案？**

“高级 → 备份全部”会包含应用外部文件中的 Rime 用户数据。也可以单独复制 `data/rime` 目录；恢复后在 Rime 中重新部署。

**升级后旧拼音引擎的数据还会使用吗？**

不会。旧版自研引擎数据不再读取，也不会导入旧备份中的 `external/engine/`。Rime 用户数据会保留。

## 用起来

**怎样切回系统键盘？**

长按地球键打开系统输入法选择器，或在系统设置中更改当前键盘。

**空格键、回车键的行为和别的 Rime 版本不一样？**

按键行为由当前 Rime 方案、Rime 配置和输入框类型共同决定；空格键长按行为也可在“按键与振动”中设置。

**键盘不出来或没反应？**

确认知了猴输入法已在系统设置中启用，并在“开发者 → 重启 Fcitx 实例”中重启。仍有问题时重启设备并检查 Rime 用户数据配置。

**怎样报告问题？**

到 [GitHub Issues](https://github.com/Sraw/youmo-ime/issues) 提交，说明应用版本、设备型号、Android 版本和复现步骤。实时日志可能包含输入内容，分享前请先检查。

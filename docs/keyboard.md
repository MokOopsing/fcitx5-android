# 键盘与手势

## 全键盘（26 键）

Rime 和共用工具使用这个全键盘。键面字母与键角符号可在键盘设置中调整；实际输入行为由 Rime 当前方案决定。

```
 q1  w2  e3  r4  t5  y6  u7  i8  o9  p0
  a@  s*  d+  f-  g=  h/  j#  k(  l)
 ⇧   z'  x:  c"  v?  b!  n~  m`   ⌫
 符  123  ，      空格       。  🌐  ↵
```

### 字母键

- **点**：打出这个字母。
- **键角上的小字**（数字和符号）有两种打法：
  - **向下滑**这个键（默认方向，可以在"按键与振动"里改成上滑或关掉）；
  - **长按**后直接松手。
- **长按**会弹出这个键的更多字符（比如 `q` 有 `1` 和 `Q`），手指滑到想要的那个再松开。
- 长按弹出哪些字符、滑动打出哪个字符，可以在 **按键与振动 → 按键字符** 里改：第一个字符也是默认的键角小字。
- 也可以在 **按键与振动 → 按键 → 按键标签** 里按输入法或子模式替换键面字母，例如在 Rime 的某个方案下显示对应字根。键角的数字/符号不变；子模式设置优先于该输入法的通用设置，没有专门标签时沿用通用设置或原字母。这只改显示，不影响点按、长按和滑动输入。只有存在多个可选输入法时，输入法选择项才可点击。

### 功能键

| 键 | 点 | 长按 / 滑动 |
|---|---|---|
| **⇧** Shift | 下一个字母大写 | 双击或长按：大写锁定 |
| **⌫** 退格 | 删除光标前的内容 | 按住连续删除；**向左滑**：选中光标前的文字，松手删除 |
| **符** | 打开符号面板 | 长按打开快速输入 |
| **123** | 数字键盘 | 长按打开 Unicode 输入 |
| **，** / **。** | 逗号、句号（打中文时是中文标点） | 长按弹出更多标点 |
| **空格** | 由 Rime 当前方案处理 | **左右滑**：移动光标；长按：执行“按键与振动”中的空格键长按行为 |
| **🌐** 地球键 | 切换 Fcitx 输入法（当前只有 Rime） | 长按：系统的输入法选择框 |
| **↵** 回车 | 按 Rime 当前方案和编辑框类型处理 | |

### 网址和邮箱输入框

在输入网址的框里，逗号和句号的位置换成 **/**、**.** 和 **.com**；在邮箱框里换成 **@**、**.** 和 **.com**。
长按 **.com** 还有 `.cn`、`.net`、`.org`。这些键直接打出原样的字符，不经过中文标点转换。

### 括号成对

打左括号或左引号时会自动补上右边的，光标停在中间；接着打右括号会跳过已有的那个，而不是再加一个；
紧接着退格会把一对一起删掉。只在后面是空白或标点的地方才补，不会在一个词中间乱加。可以在"按键与振动"里关掉。

## 数字键盘

点 **123** 打开：

```
 +   1   2   3   /
 -   4   5   6   空格
 *   7   8   9   ⌫
 ABC ,  !?#  0   =  .  ↵
```

**ABC** 回到字母键盘，**!?#** 打开符号面板。

## 键盘上方的栏

没打字时，这一栏是工具栏；打字时显示候选。

### 工具栏

- 最左边的 **>**：展开工具栏，依次是：
  - **撤销**、**重做**
  - **文本编辑**（光标图标）：见下面的文本编辑面板
  - **剪贴板**
  - **…**：更多，见"状态面板"
- 右边：**表情**按钮、**⌄** 收起键盘。
- **剪贴板提示**：刚复制了东西时（30 秒内），栏上会直接显示复制的内容，点一下就粘贴。
- 在密码框里，这一栏显示一排数字键，方便输入数字密码。
- 应用要求不记录输入时（比如浏览器的无痕模式），左边的图标会变成一个隐私图标，表示这次输入不会被学习。

### 候选

- 点一个候选上屏；候选栏可以左右滑看更多。
- 右边的 **⌄** 展开所有候选，以表格显示，可以上下翻。
- **长按候选**：弹出当前引擎提供的候选操作菜单。

## 状态面板（工具栏的 …）

| 按钮 | 作用 |
|---|---|
| 主题 | 打开"主题与大小"设置 |
| 输入法设置 | 打开 Rime 设置页 |
| 按键与振动 | 打开"按键与振动"设置 |
| 简 / 繁 | 切换简体 / 繁体输出 |
| 中文标点 / 英文标点 | 打中文时标点用全角中文标点还是英文标点 |
| 半角 / 全角 | 字母和数字用半角还是全角 |
| 右上角齿轮 | 打开设置首页 |

## 文本编辑面板

工具栏的光标图标打开，适合精确移动光标和选择文字：

- **↑ ↓ ← →**：移动光标。
- **选择**：打开后再按方向键就是扩大选区。
- **|<**、**>|**：移到开头、结尾。
- **全选**、**剪切**（有选区时）、**复制**、**粘贴**、**⌫**。
- 右上角是剪贴板。左上角 **←** 返回键盘。

## 剪贴板

开启"记录剪贴板历史"后（默认开启），复制过的内容会出现在剪贴板面板里：

- 点一条：粘贴。
- 长按一条：**置顶**（置顶的不会被自动清掉）/ 取消置顶、**编辑**、**分享**、**删除**。
- 右上角的垃圾桶：删除所有未置顶的条目。
- 密码等敏感内容（应用标为敏感的）显示为圆点。
- 复制的链接存进历史前会去掉跟踪参数（比如 `utm_source`），系统剪贴板里的原样不动。

最多保留多少条、是否显示剪贴板提示等，在 **剪贴板** 设置里调。

## 符号面板

点 **符** 打开。左边是分类：最近、常用、中文、英文、括号、箭头、数学（含希腊字母）、序号、图形、全角。
点一个符号就打出来并回到键盘。点下面的**锁**锁上后，选完符号会留在面板里，方便连续选几个；**返回**回到键盘；
**12/34** 打开数字键盘。面板会记住上次看的分类。

## 表情面板

点工具栏右边的笑脸打开。上面的标签是分类（最近使用、笑脸、人物、动物与自然、食物与饮料、旅行与地点、活动、物品、符号、旗帜），
整个列表可以上下滑。默认肤色在 **表情和符号** 设置里选；系统字体不支持的表情不显示。

## 实体键盘

接上蓝牙或 USB 键盘时，屏幕键盘会收起，候选显示在光标附近的小窗里（可以在 **高级 → 实体键盘的候选窗** 里调）。
按键行为由 Rime 当前方案决定；空格、数字和回车的用途可能因方案而异。

## 振动和按键音

默认跟随系统设置。在 **按键与振动 → 声音与振动** 里可以单独打开或关掉，并选振动强度（轻、中、强）和按键音音量（小、中、大）。

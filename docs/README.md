# 知了猴输入法使用说明

知了猴输入法是一个基于 Fcitx5 的 Android 输入法，目前只提供 **Rime** 输入引擎。键盘、剪贴板、符号、表情和文本编辑等共用功能仍可使用；输入方案和词库由用户提供并由 Rime 管理。

| [Rime 输入](rime.md) | 添加方案与词库、部署及用户数据目录 |
| [键盘与手势](keyboard.md) | 键盘布局、手势、工具栏、剪贴板、文本编辑、符号与表情 |
| [词库与短语](words.md) | 自定义短语与 Rime 用户数据 |
| [设置逐项说明](settings.md) | 共用设置和 Rime 配置项 |
| [常见问题](faq.md) | 隐私、权限、备份与故障排除 |

界面文字以简体中文为例；可在设置中切换繁體中文或 English。

# Rime 输入

幽默输入法只包含 Fcitx5 的 Rime 引擎。方案、词典和用户定制由 Rime 管理；应用不预装拼音、双拼、五笔或其他方案，也不下载 Rime 数据。

## 添加方案

1. 从可信来源取得 Rime 的方案文件（通常包括 `.schema.yaml` 和相应词典 `.dict.yaml`）。
2. 在幽默输入法设置的 **输入法 → Rime 设置** 中点击 **用户数据目录**，确认后浏览应用文件；Android 10 及以上也可长按该项直接尝试打开 `data/rime`。目录位于应用外部文件区。
3. 将方案和词典文件复制到该目录。若文件依赖其他 YAML 配置或词典，也需一并复制。
4. 在键盘的 Rime 状态/方案菜单中部署数据；如菜单暂不可用，可从 **开发者 → 重启 Fcitx 实例** 重启后再检查。

Rime 的方案文件格式和依赖因方案而异，请遵循方案作者提供的安装说明。幽默输入法不内置东风破、方案仓库或词典。

## Rime 配置

点击设置首页的输入法名称可直接打开 Fcitx5-Rime 配置。应用额外提供打开 Rime 用户数据目录的入口。若修改了方案、词典或 YAML 配置，请使用 Rime 的部署操作使变更生效。

键盘的通用外观、按键动作、剪贴板、符号和表情设置仍在应用设置页中；这些设置不替代 Rime 的方案配置。

## 数据与备份

Rime 用户数据保存在应用的外部文件目录中。应用的“备份全部”会包含该目录；备份文件未加密。也可单独复制 Rime 用户数据目录。换机恢复后，请在新设备上重新部署。
